Inspect a recovery package

Packages persist locally between launches. Keep the PAR2 volumes separately from your source files.

Import an existing PAR2 set

Import a flat directory of .par2 files. Imported verification uses PAR2 MD5 metadata only; no independent original-hash claim is made. Unsupported embedded paths and packet types are rejected.

Inspect your files

Only named package members are copied and inspected; extra files in this directory are ignored. Every expected file is accounted for, including missing files.

Try controlled damage on disposable copies

Your original files and saved recovery package stay unchanged. Each scenario makes a fresh copy.
